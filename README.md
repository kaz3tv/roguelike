# ローグライク

ブラウザで遊べる、ドット絵のローグライクゲームです。Godot 4 で作っています。
仕様は [docs/spec.md](docs/spec.md) にあります。

## ブラウザで遊ぶ

https://kaz3tv.github.io/roguelike/ （PC のブラウザ・キーボードで遊べます）

main ブランチに変更が入るたびに、GitHub Actions がテストを走らせてから Web 版を書き出し、GitHub Pages に自動で公開します（`.github/workflows/web.yml`）。
素材のクレジットはタイトル画面の C キーで表示されます（中身は `assets/credits.txt`。素材を差し替えたらここも直してください）。
最初の1回だけ、リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にしておく必要があります。

## Godot で遊ぶ・開発する

1. [Godot 4.7](https://godotengine.org/download/) をダウンロードする（インストール不要、解凍して起動するだけ）
2. Godot を起動し、「インポート」でこのフォルダの `project.godot` を選ぶ
3. 最初の1回は「編集」で開き、画像やフォントの読み込み（インポート）が終わるのを待つ
4. 右上の ▶（F5）で起動

| 操作 | キー | ゲームパッド |
| --- | --- | --- |
| 移動 | 矢印キー / WASD / テンキー | 十字キー / 左スティック（押しっぱなしで歩き続ける） |
| 斜め移動 | Q・E・Z・C / テンキー 7・9・1・3 | スティックを斜めに / 十字キー2つ同時押し |
| 攻撃 | 敵のいる方向へ移動 | 敵のいる方向へ移動 |
| その場で1ターン待つ | スペース / テンキー 5 | X |
| 階段を降りる・決定 | Enter | A |
| キャンセル・閉じる | Esc | B |
| 持ち物を開く | I / Tab | Y |
| ミニマップを出す／隠す | N | BACK（ビュー） |
| 音を消す／戻す | M | − |
| 中断してタイトルへ戻る | Esc | START（メニュー） |
| （確認用）次の階へ | F9（エディタから起動したときだけ） | − |
| 持ち物：選ぶ・使う（装備）・置く・閉じる | 上下 / Enter / X / Esc | 十字キー / A / X / B |
| タイトル：クレジット | C | Y |

ボタン名は Xbox 配置です（下 A・右 B・左 X・上 Y）。Switch 系のパッドでは位置で読み替えてください。ブラウザ版ではページを開いたあと、どれかボタンを一度押すとパッドが認識されます。

アイテムは上に乗ると自動で拾います（最大10個）。地下10階の魔王を倒すとクリアです。
タイトル画面の Enter で始まり、やられるかクリアするとリザルト（到達階・倒した敵の数など）が出ます。これまでの最高記録はタイトル画面に表示されます。

中断セーブは1枠です。Esc で中断するか、ウィンドウを閉じると保存され、次はタイトルの「つづきから」で再開できます（各階に着いたときにも自動で保存します）。続きから始めるとセーブは消えるので、やられた場面からのやり直しはできません。

## フォルダ構成

- `scenes/` 画面（シーン）
- `scripts/` ゲームの処理（GDScript）
- `assets/art/` ドット絵（16×16）。`tiles_cave/` と `tiles_abyss/` は4階・7階からのタイル。同じ名前の PNG に置き換えれば見た目が変わる
- `fonts/` ドット風フォント DotGothic16（SIL Open Font License、`fonts/OFL.txt`）
- `tests/` 自動テスト

## テスト

```
godot --headless --path . -s tests/run_tests.gd
```
