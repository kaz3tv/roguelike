# ローグライク風ゲーム 仕様 v1.1（大枠確定）

> 大まかな仕様はここで確定（2026-09-26）。細かい数値は実装しながら調整します。

## 1. コンセプト
- ブラウザで遊べる、1プレイ15〜30分程度の短めのローグライク
- ドット絵の見た目、ターン制、ランダム生成ダンジョン、死んだら最初から（パーマデス）
- 世界観：王道ファンタジー（剣と魔法）【決定】

## 2. 技術・プラットフォーム
- ゲームエンジン：Godot 4（4.7）、言語は GDScript【決定：2026-09-27 に HTML から変更】
- 配布：まずはブラウザ版（Godot の Web 書き出し）。PC・スマホアプリにも後から書き出せる
- 画面解像度：内部 320×180 を整数倍で拡大表示（ドットがにじまない設定）
- タイルサイズ：16×16px
- 文字：ドット風フォント DotGothic16（無料・商用可の OFL ライセンス）
- 操作：キーボード（矢印キー/WASD で移動、Q/E/Z/C かテンキーで斜め、Enter で階段を降りる）
- スマホ対応：当面なし（PCのキーボードのみ）【決定】
- セーブ：中断セーブ1枠と記録（Godot のユーザーデータ領域に保存）

## 3. 基本ルール
- グリッド上のターン制。プレイヤーが1歩動く/1回行動すると、敵も1回行動する
- 8方向移動（斜めあり）を仮置き
- 視界：部屋に入ると部屋全体が見え、通路では周囲1マス。一度見た場所はマップに残る
- 目的：地下10階の最深部にいるボスを倒す（階数は仮）
- 満腹度：なし（軽めのシステム）【決定】

## 4. ダンジョン生成
- 1フロア：部屋と通路型（部屋 4〜8個を通路でつなぐ）
- 各フロアに「下り階段」、アイテム数個、敵数体、たまに罠
- 3階ごとに見た目（タイルセット）と出る敵が変わる
- 10階はボス部屋固定

## 5. キャラクター
- プレイヤーは1種類（最初は）
- パラメータ：HP、攻撃力、防御力、レベル、経験値
- レベルアップで HP と攻撃力が上がる（能力選択なし）
- 職業・キャラ選択：最初はなし。後から追加できる作りにする【決定】

## 6. 敵
- 初期は 8〜10 種類程度を想定
  - 例：スライム（弱い）、コウモリ（不規則に動く）、骸骨（固い）、魔法使い（離れて攻撃）など
- 行動AI：プレイヤーが見えたら近づいて攻撃、見えなければうろつく
- 一部の敵は特殊行動（遠距離攻撃、分裂、逃げる など）
- 追加した特殊行動（2026-09-27）：おばけキノコ（動かない）、ヘビ（速い）、大スライム（分裂）、弓兵（遠くから矢）、火の精霊（倒すと爆発）、ゴーレム（遅い）。魔法使いは離れていると魔法の弾を撃つ。数値は scripts/enemy_data.gd

## 7. アイテム・装備
- 持ち物枠：10個
- 種類：
  - 回復薬（HP回復）
  - 巻物（使い捨て魔法：炎、ワープ、地図表示 など）
  - 武器・盾（装備で攻撃力/防御力アップ、ランダムで＋値つき）
  - 追加（2026-09-27）：大回復薬、力の薬、眠りの巻物、雷の巻物、大剣、復活の首飾り（1回だけ生き返る、とてもまれ）
  - アイテムごとに出る階が決まっている（深い階ほど強いものが出る）。数値は scripts/item_data.gd
- 未識別システム：なし【決定】
- お金・お店：なし【決定】

## 8. 戦闘
- 敵に向かって移動すると攻撃
- ダメージ = 攻撃力 − 防御力/2 に ±ランダム少し（最低1）
- 攻撃の命中率 95% 程度
- ダメージ数字をドット文字でポップ表示

## 9. 画面構成
- タイトル画面 → ゲーム画面 → ゲームオーバー/クリア画面（到達階・倒した敵数などのリザルト）
- ゲーム画面：中央にマップ、上部に HP・階数・レベル、下部にメッセージログ（直近3行）
- メニュー：持ち物、ミニマップ、中断
- 死んだら全部リセットの純ローグライク（引き継ぎなし）【決定】

## 10. 見た目・音
- ドット絵：16×16 タイル、限られた色数のパレット（例：32色程度）
- 素材：まず仮素材で作り、後で本番のドット絵に差し替え【決定】
- アニメーション：歩行2コマ、攻撃時に少し前に出る程度
- 音：効果音とBGMは後回し（最初は無音）
